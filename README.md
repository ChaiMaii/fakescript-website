# FakeScript Website

The official landing website for the **FakeScript (`.fks`)** programming language — a strictly zero-symbol, Ahead-of-Time compiled language.

Adapted from the [gleam-lang/website](https://github.com/gleam-lang/website) design under the **Apache License 2.0** (see `LICENCE` and `NOTICE`).

## Links

- **Compiler**: https://github.com/ChaiMaii/fakescript
- **Documentation**: https://chaimaii.github.io/fakescript-docs/
- **Docs Source**: https://github.com/ChaiMaii/fakescript-docs

## Local Preview

This is a zero-build static site — serve it with any HTTP server:

```bash
python3 -m http.server 8000
```
