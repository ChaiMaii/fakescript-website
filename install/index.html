Install FakeScript

Zero dependencies beyond Go 1.22+. Build fksc in under a second.

Quick install (fksc + fkspm)

Requires Go 1.22+. Run the visual installer to install both fksc and fkspm and add them to your PATH:

Windows (PowerShell)

irm https://raw.githubusercontent.com/ChaiMaii/fakescript/main/install.ps1 | iex

Linux / Debian / macOS

curl -fsSL https://raw.githubusercontent.com/ChaiMaii/fakescript/main/install.sh | sh

Build from source

The entire FakeScript compiler lives in a single Go source file (fksc.go) using only the Go standard library. Clone the repository and compile it for your platform:

Windows (PowerShell)

git clone https://github.com/ChaiMaii/fakescript.git
cd fakescript
go build -o fksc.exe fksc.go
.\fksc.exe run examples\showcase.fks

Linux / Debian / macOS

git clone https://github.com/ChaiMaii/fakescript.git
cd fakescript
go build -o fksc fksc.go
./fksc run examples/showcase.fks

CLI commands

fksc build program.fks    # Compile to a standalone native binary
fksc run program.fks      # Compile and run immediately
fksc emit program.fks     # Print formatted Go source code
fksc check program.fks    # Lex, parse, and type-check only
fksc version              # Print compiler version
