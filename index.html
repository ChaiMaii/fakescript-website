FakeScript is a zero-symbol language for building type-safe native programs that run fast!
Read the Docs

Strictly zero punctuation symbols — no braces, no quotes, no parentheses, no semicolons. Every construct is written in plain English words and Ahead-of-Time compiled into standalone native binaries. 

import print

fn main do
  ln of print contains say hello friend end
end

exec main

Native AOT speed

FakeScript is never interpreted. The fksc compiler lowers .fks programs through a full Lexer, Recursive-Descent Parser, Type Checker, and Go Code Generator into unboxed native machine code.

With native int64 arithmetic, zero boxing, and direct function calls, recursive fib 32 computes in under 10 milliseconds. 

fn fib with num n returns num do
  if n is at most 1 do
    give back n
  end
  let a be exec fib with n minus 1
  let b be exec fib with n minus 2
  give back a plus b
end

Ready when you are

The entire fksc compiler lives in a single zero-dependency Go file. Build it once with go build -o fksc fksc.go and enjoy a symbol-free CLI right out of the box.

Run scripts immediately with fksc run, inspect formatted Go output with fksc emit, or type-check in milliseconds with fksc check. 

➜ (main) fksc check examples/showcase.fks
OK examples/showcase.fks
➜ (main) fksc run examples/showcase.fks

Here to help

A strict zero-symbol lexer and two-pass static type checker catch stray punctuation, type mismatches, arity errors, and invalid loop control before a single binary is built. 

app.fks:4: error: symbol "=" is not allowed in FakeScript
  use plain English keywords only
  | let score = 42

app.fks:8: error: cannot assign text to variable "score" of type num
  | set score to say ninety end

Lazy actions & batteries included

Assigning a void action to a variable automatically creates a deferred thunk that runs only when invoked later — paired with block-level lexical scoping, typed lists, and interactive ask standard input.

Built-in print, math, text, file, and time modules emit only the Go standard library imports your program actually uses. 

import print
import text

note deferred lazy thunk
let greet be ln of print contains say welcome end

let items be list of say apple end and say cherry end end
for each item in items do
  ln of print contains upper of text contains item
end
greet
